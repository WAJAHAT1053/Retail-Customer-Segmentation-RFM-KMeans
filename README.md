# Retail Customer Segmentation — RFM & K-Means Analysis

Segmenting retail customers into behavioural profiles using RFM analysis and K-Means clustering.

## Overview
Processed 1,067,371 transaction records from the UCI Online Retail II dataset, engineered RFM (Recency, Frequency, Monetary) features, and applied K-Means clustering to identify 4 distinct customer segments.

## Key Results
- **Silhouette Score: 0.591**
- **4 segments identified:** Champions, Loyal, At-Risk, Lost Customers
- Optimal cluster count determined via Elbow Method + Silhouette Score

## Tech Stack
Python · Pandas · Scikit-Learn · Matplotlib · Seaborn
